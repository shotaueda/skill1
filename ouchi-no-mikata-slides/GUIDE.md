# 使い方ガイド（はじめての方へ）

このスキルを使って、株式会社花光向けの報告スライドを作るための手引きです。
**プログラミングの知識は不要**。基本は「Claude（AI）に日本語でお願いするだけ」です。

---

## 1. これは何？（1分で）

- **才流（さいる）という有名なBtoB資料テンプレ**の“見せ方の型”だけを借りて、
  **配色と装飾を花光向けのオリジナル**に着せ替えた、スライドの「共通デザインの素」です。
- 配色は**寒色系（ネイビー×ブルー）**。誠実で信頼感のあるトーンにしています。
- これを使うと、Claudeが毎回ゼロから考えず、**いつも同じトーン・同じ品質**のスライドを作れます。
- 単純な報告だけでなく、**アイコン付きの比較パネルや「認識のズレ」を見せる分析スライドなど、
  コンサルティング会社の資料に近い作り込み**まで対応できます。
- 出力は **PowerPoint（.pptx）ファイル**。そのままクライアントに送れます。

イメージ：**「料理のレシピ集＋食器のセット」**をAIに渡しておくと、
「今日はこの食材で」と言うだけで、毎回きれいに盛り付けてくれる——そんな道具です。

---

## 2. 準備（最初の1回だけ）

1. `ouchi-no-mikata-slides.zip` を解凍します。
2. 中身の **`SKILL.md` があるフォルダごと**、お使いのClaude環境にスキルとして登録します。
   （Claude Code や スキル対応の環境で「スキルを追加」する操作。やり方は環境のヘルプ参照）
3. これで準備完了。あとは普通に話しかけるだけです。

> 花光の白ロゴを表紙に入れたい場合は、**白いロゴのPNG画像**を1枚用意しておきます（後述）。

---

## 3. いちばん簡単な使い方（コードを書かない）

Claudeに、**ふつうの日本語でお願いするだけ**です。例：

> **「花光向けのWeb集客 月次レポートを作って。登録したスライドスキルを使ってね。
> 今月の数字は ①自然検索 24,310（前月+18%）②問い合わせ 86件 ③CV率 3.4%。
> 来月は『追従CTA設置』『フォーム改善』『地域ページ追加』を提案したい。」**

すると Claude が、表紙→サマリー→グラフ→課題と施策→…→締め、と
**スライドを組み立てて .pptx を返してくれます**。

もう少し込み入った分析資料もお願いできます：

> **「CRMのデータと現場の実感がズレている、という課題を1枚で見せたい。
> 担当者は『問い合わせは増えている』と思っているが、実際は低単価の問い合わせばかり増えている、
> という内容で。」**

> **「施策の実行体制を組織図で」「市場規模をTAM/SAM/SOMで整理して」
> 「①発見→②分類→③ルール化→④定着、の4ステップをアイコン付きで見せて」**

直したいときも、言葉で言うだけ：

> **「3枚目のグラフを棒グラフにして」「競合比較の表をもう1社追加」「全体的に文字を少し大きく」**

## 4. コピペで使えるプロンプト例

| やりたいこと | お願いの仕方（例） |
|---|---|
| 月次レポート一式 | 「花光向けの月次レポートを、登録したスライドスキルで作って。データは〜」 |
| 1枚だけ作る | 「競合比較のスライドを1枚だけ。当社/A社/B社で、KBFは〜」 |
| 数字を渡して作る | 「このCSVのGA4データでKPIハイライトのスライドを作って」＋ファイル添付 |
| 提案ロードマップ | 「3フェーズのロードマップを作って。STEP1〜3はそれぞれ〜」 |
| 認識ギャップの整理 | 「現場の思い込みとデータの実態がズレている話を1枚で。現場の声は〜、実際のデータは〜」 |
| 実行体制・市場規模 | 「実行体制を組織図で」「市場規模をTAM/SAM/SOMで」「優先順位をピラミッドで」 |
| 事例・ビフォーアフター | 「フォーム改善のビフォーアフターを1枚で。項目数や完了率の変化を入れて」 |
| 花光ロゴを入れる | 「表紙と締めに、添付の花光の白ロゴを入れて」＋白ロゴPNGを添付 |
| 修正 | 「2枚目、文字がはみ出してる。直して」「色みをもう少し落ち着かせて」 |

## 5. Claudeに渡すと仕上がりが良くなる情報（チェックリスト）

- **目的**：何を伝え、何を判断/納得してもらう資料か
- **相手**：株式会社花光（の誰に）
- **対象期間**：例「2026年6月度」
- **載せる数字**：KPI、件数、順位など（出典も。例：GSC / GA4 / Salesforce）
- **各スライドで一番言いたいこと（結論）**：これが各ページ上部の「メッセージ」になります
- **ロゴの有無**：花光の白ロゴ画像があれば添付
- **（分析スライドの場合）現場の声とデータの数字**：両方あると「認識ギャップ」のスライドが作れます

> 数字や結論が曖昧なときは、Claudeが1回だけ「何の数字が要りますか？」と聞きます。
> そこで具体的に答えると、より正確な資料になります。

## 6. どんな「見せ方」ができる？（早見表）

「こういうデータ → こういうスライド」になります。むずかしく考えず、データを渡せばOK。

| 渡すデータ | 仕上がるスライド |
|---|---|
| 数値・実績（PV、順位、件数…） | 大きな数字のハイライト／推移グラフ＋読み解き／コンパクトなKPIストリップ＋内訳表／KPIファネル |
| 比較（自社vs競合、料金プラン…） | ◎○△✕ の比較表／左右で対比＋矢印（アイコン付き見出しも可） |
| 手順・計画（フロー、ロードマップ） | STEP矢印のロードマップ／アイコン付きプロセス図／ガントチャート |
| 啓発・解説（仕組み、リスク、対策） | 3つの特長カード／Q&A／原因→対策の対比 |
| 事例・効果（ビフォーアフター） | 左右対比カード／事例カード（数値のビフォーアフター付き） |
| 現場の声とデータのズレ | ペルソナの発言＋「見えているデータ」≠「実際に起きていること」＋結論の一言 |
| 市場・戦略の整理 | TAM/SAM/SOM の同心円／優先順位ピラミッド／簡易組織図／ベン図／ポジショニングマップ |
| 顧客理解 | ペルソナカード／カスタマージャーニー |
| まとめ・締め | チェック付きの要点リスト＋下部の結論バンド |
| 表紙・区切り・締め | 表紙／章扉（大きな番号）／締めページ |

## 7. このテーマが「やらないこと」

クライアント報告として不要・不適切なものは入れません。

- ❌ **おうちのミカタの家マーク**（このテーマでは使いません）
- ❌ **電話番号**
- ❌ **「メールで相談」などのCTAボタン**
- ❌ タイトル下の飾り線、スライド端の飾りカラーバー

もし必要になったら、その都度Claudeに個別に指示してください。

---

## 8. 花光の白ロゴの入れ方

- ロゴは**白いロゴ画像**を使い、**濃い背景の表紙・締めページにだけ**置けます
  （白いロゴは白い背景では見えないため）。
- 使い方：Claudeに「表紙と締めに花光の白ロゴを入れて」と伝え、**白ロゴのPNGを添付**するだけ。
- ロゴが無いときは、代わりに「株式会社花光」の白文字が入ります（そのままでも成立します）。

---

## 9. 困ったときは（言葉で直せます）

| 症状 | Claudeへの一言 |
|---|---|
| 文字がはみ出している | 「◯枚目、文字がはみ出してるので直して」 |
| 余白が偏っている／窮屈 | 「◯枚目のレイアウトを整えて」 |
| 色を変えたい | 「強調のブルーをもう少し濃く」など（※基本配色は崩さない前提で） |
| グラフの種類を変えたい | 「折れ線→棒グラフにして」 |
| もっと情報を詰め込みたい | 「このスライド、グラフだけじゃなく読み解きも添えて」「アイコン付きの一覧にして」 |
| ロゴが表示されない | 白ロゴを添付し「濃い背景の表紙に入れて」と指定 |

## 10. 用語ミニ辞典

- **スキル**：Claudeに覚えさせる“やり方の説明書”。これを登録すると毎回同じ品質で作れる。
- **.pptx**：PowerPoint のファイル形式。クライアントに送れる編集可能ファイル。
- **メッセージライン**：各スライド上部の「結論を1行で言う帯」。才流の型の肝。
- **結論バンド**：情報量の多いスライドの最下部に置く、全幅の色帯の一言まとめ（新設）。
- **アーキタイプ**：スライドの“見せ方の型”（比較表、ロードマップ、認識ギャップ分析等）。
- **kicker（キッカー）**：タイトルの上に付く小さな見出しラベル（例「サマリー」）。
- **QA**：できたスライドを画像にして、はみ出し等を点検する作業。Claudeが自動でやります。

## （上級者向け）自分でコードを動かす場合

技術がある方は、AIを介さず直接生成もできます。

```bash
# スキルのフォルダ内で一度だけ
npm install pptxgenjs

# build.js を書いて（build_reference_deck.js が見本）生成
node build.js
python /mnt/skills/public/pptx/scripts/rezip.py out.pptx   # 必須

# プレビュー（画像化して目視）
python /mnt/skills/public/pptx/scripts/office/soffice.py --headless --convert-to pdf out.pptx
pdftoppm -jpeg -r 120 out.pdf slide
```

- 共通パーツは `theme.js`、書き方の見本は `build_reference_deck.js`（全26枚・全パーツ網羅）、
  仕上がり見本は `reference-deck.pptx`。
- アイコン素材は `assets/icons/`（白シルエットPNG）、背景の質感素材は `assets/dot-texture-*.png`。
- 詳しい仕様（色トークン・全関数のパラメータ・情報密度の組み方）は `SKILL.md` を参照。
